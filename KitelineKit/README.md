# KitelineKit

Shared SwiftUI components used by both the Mac app and the iPhone app: the conversation views, data models and networking. `build.sh` compiles this folder into the Mac app as the `KitelineKit` module (with `-D KITELINE_MAC`). The iPhone, iPad and Apple Watch apps themselves (app shell, pairing, settings, widgets, Xcode project) are not open source.

Mac 端和 iPhone App 共用的 SwiftUI 组件：对话页、数据模型和网络层。`build.sh` 把这个目录作为 `KitelineKit` 模块编进 Mac 端（带 `-D KITELINE_MAC`）。iPhone、iPad、Apple Watch App 本身（App 外壳、配对、设置、小组件、Xcode 工程）不开源。
