# Kiteline 电脑端（Windows / Linux）更新记录

## 1.0.37（2026-11-11）

### 改进

- **新建会话组时可直接选颜色**：新建面板里有一排九种颜色；右键菜单「颜色」中每一项前面显示对应的色块。

### 问题修复

- 修复会话组一键建群时，组名被当作第一条群消息发给每个成员会话、并让会话另起群名的问题：现在群名直接使用会话组的名称，建群时不打扰组里的会话。
- 修复「全部 · 标记 · 工作中 · 待确认」等筛选按钮放不下时被截断、无法滚动查看的问题，现在用鼠标滚轮即可左右滚动。
- 修复新标签页「选择要在此显示的会话」列表较长时无法滚动的问题。
- 修复分屏较窄时，刚打开的群聊标签被挤到标签栏看不见的位置的问题。


## 1.0.36（2026-11-11）

### 新功能

- **会话组**：把同一阶段的相关会话放进一个会话组，组名、颜色和组里的会话在电脑和手机上同步。切到某组时，组里的会话各占一列同时显示；标签栏最左侧显示当前组的颜色和名称，点开即可切换。每组显示待确认和新消息的角标以及最需要处理的一件事，展开后正在工作的会话状态点会闪烁。组名和颜色可随时修改（九种颜色），还能一键把组里的会话拉成群。
- **会话列表分为「会话」「群」「会话组」三个页签**：状态筛选和显示方式只在「会话」页签中；设备、项目筛选收成一行，显示当前选择，点开后再更换；「群」页签单独列出会话群，建群按钮也在这里。首次打开时会显示说明。
- **新手引导加入微信小程序码**：「连接手机」一步同时提供 iPhone App 和微信小程序的二维码，安卓手机可使用 Kiteline 微信小程序。

### 改进

- **会话列表更简洁**：会话第二行只显示状态（待确认的工具、正在运行的工具、可能停滞、出错或空闲）和任务进度，不再显示截短的回复内容，鼠标停在上面可看完整说明。
- **新消息提示更准确**：在任一设备上看过的会话，其他设备不再提示新消息；会话之间往来引起的回复不再算作新消息。
- **会话群更省 token**：群里的会话只在遇到问题、需要配合或交接，以及被直接询问时才发言，不再发送「收到」、致谢和进度播报。
- **长对话更流畅**：对话页平时只显示最近的消息，更早的轻点「查看更早的消息」展开，回到底部后自动收起。聊天记录越来越长时，滚动和新消息上屏不再越来越卡。

### 问题修复

- 修复关闭显示器再打开、窗口被系统调整位置或大小后，对话停在中间或最上方、新消息也不再自动滚到底部的问题。


## 1.0.35（2026-11-09）

### 新功能

- **防火墙拦截提示与一键放行**：Windows 防火墙（或 Linux 的 ufw）阻止了手机或其他电脑连入时，就绪检查中会给出提示，轻点「一键放行」并在电脑上确认授权即可放行，只放行 Kiteline 本身和它用到的端口。添加 Kiteline 电脑连接超时时，也会提示检查对方电脑的防火墙。

## 1.0.34（2026-11-09）

### 新功能

- **添加其他 Kiteline 电脑**：在客户端「设置 → 来源」中点「添加 Kiteline 电脑」，输入另一台电脑（Mac、Windows 或 Linux）的地址和它「手机访问」页上的验证码，在那台电脑上点「允许」后，两台电脑互相加为来源，对方的会话直接出现在会话列表中，可查看、回复、确认，操作由会话所在的电脑执行，适合家里和公司各一台的异地办公。电脑之间直接连接（局域网、公网地址或自建组网），不经过 Kiteline 的中继。手机配对其中一台即可，任一台在线都能连接。
- **支持 pi**：电脑上装有开源编程 Agent pi 时，Kiteline 自动安装对应插件，会话可在手机和客户端中查看（状态、完整记录、思考过程和工具调用）；在 tmux（Linux）或终端窗口（Windows）中运行时，还可发送消息（忙时自动排队）、中断和关闭会话。「今日用量」和用量页计入 pi 的 token 和花费。

### 安全

- **配对验证码防猜测**：同一个验证码输错 5 次即作废并自动换新；来自公网地址的错误尝试过多时，暂停公网配对一小时；来自公网地址的手机配对也需在电脑上确认。

## 1.0.33（2026-11-09）

- **思考内容可复制，长思考随时收起**：展开的思考内容右上角可一键复制；内容较长时，底部也有「收起思考」，无需滚回顶部。

## 1.0.30（2026-11-07）

### 问题修复

- **设备列表中正确显示微信小程序**（Windows、Linux）：之前配对的微信小程序原先显示为「浏览器」，下次连接时会自动改为「微信小程序」。
- **Claude 的提问一定能看到选项**：部分会话中 Claude 提问时，只显示一张写着「需要输入」、没有任何选项的确认卡片。现在会显示完整的问题和选项，可直接作答；同时，确认卡片上的「允许」不再被当作对提问的回答。更新后新开或恢复的会话生效。
- **消息可交给电脑翻译**：翻译服务新增「电脑翻译」，并在「自动」模式下优先使用：连接 Mac 时由 Mac 的系统翻译在电脑上完成，连接 Windows / Linux 电脑时由电脑代为联网翻译，连接更稳定。
- **消息翻译更稳定**：所选的翻译服务无法连接、被限流或额度用完时，自动改用另一个服务，不再每条消息都显示翻译失败。

## 1.0.28（2026-11-06）

### 新功能

- **消息翻译**（Windows、Linux）：每条消息下方新增「翻译」，点一下即可把这条消息翻译为所选语言，再点「原文」还原；鼠标移到「翻译」上会同时显示设置按钮。第一次使用时可选择原文语言（默认自动检测）、目标语言和翻译服务（Google 翻译或 MyMemory，均无需注册或填写密钥；「自动」模式下 Google 翻译不可用时改用 MyMemory），之后在消息旁的设置按钮或「设置 → 通用」中随时修改。代码块、行内代码和链接保持原样，表格按格翻译。打开「自动翻译助手的回复」后，与目标语言不同的回复显示在屏幕上时会自动翻译。也可在右键菜单中选择「翻译」。

### 问题修复

- **Windows 上用搜狗等输入法打字不上屏**（Windows）：部分用户在消息输入框中用搜狗等中文输入法打字时，候选框正常弹出，选字后文字却没有进入输入框。现已修复，输入法在各输入框中都能正常上屏。
- **从手机发送命令后不再多出一条英文说明**（Windows、Linux）：从手机给 Claude Code 会话发送斜杠命令（如切换思考强度）后，对话中会多出一条以「local-command-caveat」开头的英文说明，并显示为你发送的消息。现已不再显示。

## 1.0.27（2026-11-05）

### 新功能

- **支持 CodeBuddy / WorkBuddy 和 ZCode**（Windows、Linux）：电脑上装有腾讯 CodeBuddy Code、WorkBuddy 或智谱 ZCode 时，Kiteline 自动安装对应插件，会话可在手机上查看（状态、完整记录、任务清单），「今日用量」和用量页计入它们的 token。CodeBuddy Code 在 Linux 上用 tmux 运行时，还可发送消息、允许或拒绝命令、回答提问、中断和关闭会话；WorkBuddy 桌面版和 Windows 上的会话只能查看。
- **支持 Antigravity 和 Muse Code**（Windows、Linux）：电脑上装有 Google Antigravity 或 Meta Muse Code 时，Kiteline 自动安装对应插件，会话可在手机上查看（状态、完整记录），「今日用量」和用量页计入它们的 token。在 Linux 上用 tmux 运行 Antigravity 命令行或 Muse Code 时，还可发送消息、中断和关闭会话，Antigravity 还可允许或拒绝命令、回答提问（Muse Code 的命令请在电脑上确认）；Antigravity 桌面版、IDE 和 Windows 上的会话只能查看。
- **支持 trae-agent**（Windows、Linux）：电脑上装有字节跳动开源的 trae-agent 命令行时，Kiteline 自动安装对应插件，可在手机上查看它的任务和完整记录，「今日用量」和用量页计入它的 token；在 Linux 上用 tmux 运行时还可从手机发任务。trae-agent 本身没有审批和提问，也不能中断正在执行的任务。Trae IDE 的对话数据是加密的，暂不支持。
- **Windows 上从手机操作 Antigravity**（Windows）：Antigravity 命令行在 Windows 终端里运行时，也能从手机回复、允许或拒绝命令、回答提问、中断和关闭会话，不用 tmux。其他命令行 agent 在 Windows 上逐家实测后开放。
- **ZCode 可从手机操作**（Windows、Linux）：使用 API Key 添加的模型时，可以从手机给智谱 ZCode 的会话发消息，这一轮要确认的命令、要回答的提问会出现在手机上，也可以中断；电脑上的 ZCode 退出再打开后能看到这一轮。使用 ZCode 账号登录的模型的会话只能在手机上查看。电脑上 ZCode 窗口里发起的那一轮，仍请在电脑上确认，对话里有提示。
- **插件说明更清楚**（Windows、Linux）：设置 → 插件中，每个插件下面逐条列出做不到的功能（附原因）和还没实测的功能，开启前就能知道它在手机上能做什么、不能做什么。

### 改进

- **会话列表改为浮动面板**（Windows、Linux）：主窗口左侧的会话列表与窗口四边、右侧内容各留出间距，以圆角面板浮在窗口上，并带一层柔和的投影，与 macOS 新版的侧栏样式一致。面板与右侧内容之间的空隙可直接拖动来调整列表宽度，空隙的上沿可拖动窗口；原先调整好的列表宽度保持不变。

## 1.0.26（2026-11-04）

### 新功能

- **支持 Kimi Code、Hermes、Grok Build**（Windows、Linux）：电脑上装有 Kimi Code（月之暗面）、Hermes（Nous Research）或 Grok Build（xAI）时，Kiteline 自动安装对应插件。它们的会话可在手机上查看（状态、完整记录、任务清单）；在 Linux 上用 tmux 运行时，还可发送消息、允许或拒绝命令、回答提问、中断和关闭会话（Windows 上只能查看）。「今日用量」和用量页计入三者的 token（Hermes 含花费）；Kimi Code 会员的额度和加油包余额可在插件下打开「显示订阅额度」后查看。
- **远端电脑上可以后台运行 Claude Code，不再打开 VS Code**（Windows、Linux）：在经 SSH 连接的电脑上新建任务、恢复会话时，Kiteline 可以直接在那台电脑上后台运行 Claude Code，不再在本机打开 VS Code 窗口，也减少 VS Code 的内存占用。按设备开启，默认关闭：在设置 →「来源」中点击那台电脑的「后台运行…」，或点击会话页上方「当前会话支持后台托管 Claude」的提示，先检测出口 IP，确认地区、网络和代理无误后再开启。后台运行的 Claude Code 就在项目所在的电脑上运行，使用与 VS Code 中的 Claude Code 相同的网络设置（代理、证书、接口地址），每次启动前都会核对，无法确认时改在 VS Code 中打开并告知原因。开启后，之后发送消息、确认、关闭都不切换前台，本机锁屏时也能操作；SSH 断开或本机睡眠后，会话仍在那台电脑上继续运行。VS Code 中正开着的会话可以一键转到后台，在 Claude 空闲时点击「在 VS Code 中打开」又可以转回 VS Code 接着这段对话。会话终端中新增的「claude」显示这个会话原本的界面，可以直接操作；在那台电脑的终端里运行 python3 ~/.ccpulse/ccpulse-watch.py attach 也能实时查看和操作。会话页的提示可以选择「不再提示」。那台电脑上只在 VS Code 中用过 Claude Code、没有单独安装命令行版也可以使用；Windows 电脑暂不支持。
- **手机上的操作不再打扰你用电脑**（Windows、Linux）：从手机发消息、批准或拒绝命令、回答 Claude 的提问、中断回复时，Kiteline 现在把内容直接交给 Claude Code 会话，不再把 VS Code 切到前台粘贴、按键。你在电脑上打字、使用其他程序都不受影响，电脑锁屏时也能发送。Claude 等你确认时，VS Code 中照常显示确认框，在手机或电脑上任一处作答即可，另一处的确认框随之关闭；这时从手机发出的消息会排在确认之后送达。Claude 正在工作时发出的消息，与在电脑上趁它工作时输入的一样，会在它做完手头这一步后立即交给它，不必等这一轮回复结束；这类消息在 Kiteline 的对话中照常显示，在 VS Code 中不单独显示。回答提问时，Claude 收到的是你选中的选项本身。由手机发来的消息在 VS Code 中上方注明「Prompt from the kiteline plugin」。适用于 Kiteline 更新后新开或恢复的 Claude Code 会话，VS Code 中和终端中的都可以；更新前已经开着的会话仍按原来的方式发送。在终端中运行的会话现在不用 tmux 也可以从手机回复；从别的电脑经 Remote-SSH 连到这台 Linux 电脑、在 VS Code 中运行的会话，原先只能在打开 VS Code 窗口的那台电脑上操作，现在这台电脑上的 Kiteline 也能直接发送。
- **新任务可以打开任意文件夹**（Windows、Linux）：「新任务」的项目列表最后新增「打开其他文件夹…」，可以选择还没用过 Claude Code 的目录（例如刚建好的项目），在其中新建会话。在本机使用系统的选择文件夹窗口；对经 Remote-SSH 连接的电脑，可以在 Kiteline 中逐级浏览那台电脑上的文件夹，支持筛选、显示隐藏文件夹和新建文件夹，Git 仓库会单独标出。新版 iPhone App 中的「新任务」也可以这样浏览这台电脑上的文件夹。

### 改进

- **iPhone 实时活动写明在等哪条命令**（Windows、Linux）：这台电脑上的会话等你批准命令时，iPhone 锁屏和灵动岛上原先只显示「请求权限确认」，现在直接写出命令，例如「Bash: npx prisma migrate deploy」。

### 问题修复

- **英文界面下世界模式和数据流的文字修整**（Windows、Linux）：界面为英文时，世界模式右下角的操作说明、按钮提示和私聊框原先仍显示中文，现在随界面语言显示；数量为 1 时不再写成复数（如「1 sessions」）；数据流底部四块的标题不再重复，工具通道的名称不再压住进度条。
- **只读分享页面中的步骤不再重复工具名**（Windows、Linux）：同事浏览器中看到的执行步骤原先显示为「Bash · Bash: npm test」，现在显示为「Bash: npm test」。

## 1.0.25（2026-11-03）

### 新功能

- **Agent 可以用网页回复**（Windows、Linux）：需要用图表、对比表、流程图说明的结论，agent 可以写成一个网页发到对话中，显示为一张带标题和说明的卡片，同时推送到手机；点击卡片即可用默认浏览器打开。Kiteline 自动更新截图技能，告诉 agent 何时适合用网页回复。
- **提示词链接**（Windows、Linux）：点开他人发来的 Kiteline 提示词链接，会打开「新任务」并填好提示词，链接中注明的项目在电脑上能对应到时自动选中，内容需本人确认后才开始。右键自己发出的消息，选择「复制为提示词链接」即可生成链接发给同事或贴进 PR 评论。Kiteline 启动时自动注册 kiteline:// 链接。
- **iPhone 实时活动**（Windows、Linux）：这台电脑上的 Agent 工作或等待确认时，已配对的 iPhone 会在锁屏和灵动岛上实时显示会话标题与状态，轻点即可进入对应会话；需要 iPhone 上的 Kiteline 1.8 或更高版本，可在 App「设置 → 推送通知」中关闭。按 Apple 的规定，实时活动的内容不能加密，会话标题和状态以明文经 Apple 推送服务发送，对话内容不会发送。
- **分享只读链接**（Windows、Linux）：在会话菜单中选择「分享只读链接…」，可生成一个局域网网址发给同事。和电脑在同一网络（Wi-Fi）中的人无需安装 Kiteline，用浏览器即可查看这个会话的对话和执行的步骤（不含思考过程、图片和关键信息）；会话有进展时，对方的页面自动更新。页面和内容直接由电脑提供，不经过任何服务器。有效期可选 1 小时、24 小时或 7 天，可随时停止分享。

### 改进

- **「今日用量」可随时刷新**（Windows、Linux）：「今日用量」标题旁新增刷新按钮，点一下即重新读取各台电脑的额度和今天的用量。Claude Code 和 Codex 的额度在每次回复时更新，一段时间没有使用的电脑会保持上次的读数。

## 1.0.24（2026-11-03）

## 1.0.0（2026-10-22）

### 新功能

- **在 iPhone 上使用 Windows / Linux 电脑中的 Claude Code**：通过 iPhone 上的 Kiteline App 查看和回复这台电脑上的会话，功能与 Mac 版一致。
- **配对**：扫描控制台中的二维码，或在手机上输入 6 位配对码；同一 Wi-Fi 下，手机可自动发现这台电脑。
- **远程访问**：手机不在同一 Wi-Fi 时经 Kiteline 中继连接，全程端到端加密。
- **发送消息**：支持 VS Code 中的会话（Windows 模拟键盘输入；Linux 支持 X11 和 Wayland）以及终端中的会话（Windows 直接写入控制台；Linux 需在 tmux 中运行）。
- **支持 Wayland 桌面**（Linux）：新增 Kiteline 配套 VS Code 扩展（随 Kiteline 提供，在本机安装），可在 Ubuntu 22.04 / 24.04、Fedora 等默认使用 Wayland 的桌面中向 VS Code 中的会话发送消息、处理确认和新建任务。窗口不在前台、屏幕已锁定或当前标签页不是目标会话时，不会进行任何按键操作。
- **按住说话**：使用本机离线运行的 Fun-ASR-Nano 语音识别，首次使用时下载约 1 GB 的模型。
- **朗读**：默认使用微软神经网络语音（需联网，待朗读的文字将发送至微软服务器合成）；Windows 另可使用系统自带的中文语音作为离线备用。
- **完整功能**：支持锁屏推送、待办、今日动态、用量、历史会话、项目和定时任务。
- **控制台**：仅在这台电脑的浏览器中打开，入口一次有效，访问令牌不会出现在地址栏、浏览器历史或 Cookie 中。
- **就绪检查**：缺少发送消息所需的组件或权限时说明原因，并支持一键安装（Linux 支持 apt、dnf、pacman 和 zypper）。
- **开机自动启动**：Windows 写入登录启动项，Linux 写入桌面自启动项；重复打开 Kiteline 时只会打开控制台。

### 改进

- 会话在 VS Code 远程连接（Remote-SSH）中运行时，发送失败的提示会说明编辑器窗口所在的电脑及处理方法。
- Linux 缺少 xclip 或 xsel 时，就绪检查会直接提示。

### 问题修复

- 修复 Linux 上自建桥接网卡（如 br-vm、br-lan）的局域网地址未包含在证书中，导致手机经该地址连接时 HTTPS 校验失败的问题。
- 修复手机查看过的图片缓存不会清理的问题；现在 14 天未使用的缓存会自动清理。
- 修复 Windows 上在手机端新建任务后，VS Code 中只预填了内容、未提交的问题。
- 修复 Windows 上新建任务的内容包含 +、&、% 等字符时被截断的问题。
- 修复 Windows 终端中的 Claude Code 收到消息后不提交、多行消息被拆分发送的问题。
- 修复同一项目下有多个会话且其中一个尚未发送过消息时，消息被预填进新开空白标签页的问题。

### 安全

- 明文 HTTP 端口仅在本机开放，局域网内只提供 HTTPS，配对二维码使用 HTTPS 链接。
- 本机根证书只能为局域网和本机地址签发证书；慢速请求和超大请求会自动断开；配对码输错次数过多时按来源锁定；依赖按锁定文件安装并逐一校验哈希。

### 移除

- 不再提供网页版：在浏览器中访问本机服务地址时仅显示连接说明，控制台中移除「打开网页版」。
