# 确认请求、计划审批和提问

[English](approvals.md)

Agent 停下来等你时，Kiteline 把它推到手机和手表上。

## 命令和文件改动

看清完整的命令或改动，再选「允许」「拒绝」或「总是允许」，锁屏通知上就能直接点。

高风险命令（如 `rm -rf`、`git push --force`、`sudo`）一律二次确认。请求等了 10 分钟、30 分钟还没处理，会再提醒一次。

## 计划

计划模式下的 Claude Code 会话写好计划后，在手机上看完再批准或拒绝。也可以在手机上把会话切到计划模式。

## 提问

Agent 问选择题时，选项变成按钮，点一下就回；也可以选「其他」，打字或说话回答。

## Apple Watch

抬腕允许、拒绝或选选项；Series 9、Ultra 2 及更新的型号支持双指互点。表盘复杂功能显示有几件在等你。

## 勿扰时段

勿扰时段内只推送需要你确认的请求，不会被日常进展吵醒。

## 目标

设了目标（`/goal`）的会话会一轮轮做下去，直到达成。进行期间每一轮结束不再单独推送「已完成」，只在目标达成、无法达成或中途停下（比如接口出错、用量到上限）时提醒你。
