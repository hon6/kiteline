# 隐私与安全

[English](privacy.md)

## Kiteline 绝不做的事

- 登录 Claude 或任何 AI 服务；
- 读取、保存或转发你的 API Key、会话令牌或登录信息；
- 调用模型接口；
- 修改你的 Agent 或它的配置。

Agent 照旧在你的电脑上、用你自己的账号运行，费用照旧走你现有的套餐。

## Kiteline 会加的东西

给 Agent 装四项技能（截图、网页测试、待办与关键信息、任务阶段），以及额度显示、进度提醒用的小插件。它们放在各 Agent 自己的目录里，不会写进你的项目，每一项都能关掉。网页测试用的 Playwright 装在 Kiteline 自己的目录里。

## 配对与设备

不用注册账号。每台手机有自己的设备令牌，电脑上只存它的摘要，可以单独停用。配对码 10 分钟内有效，只能用一次。手机和手表上的每个操作都记在电脑的操作记录里。

## 数据去哪了

对话和代码只在你的电脑和手机之间传输，端到端加密。连接方式见[远程访问](remote-access.zh-CN.md)。

## 使用统计

电脑每 15 分钟向 Kiteline 服务器发送一份汇总：设备类型和版本、用了哪些 Agent 和模型、token 数量和你设置的显示名，所有编号都经过哈希。不包含对话、代码、文件名、路径和会话标题。可在「设置 → 发送使用统计」里关闭。

## 语音

按住说话的转写在你自己的电脑上进行（普通话用 Fun-ASR-Nano 离线识别），录音不离开你的设备。如果选用微软的声音朗读回复，被朗读的文字会发给微软合成语音。
